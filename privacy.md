# Polityka prywatności

Aplikacja jest prywatna i niekomercyjna. Mogą z niej korzystać wyłącznie zaproszone osoby.

## Dane

- Adres e-mail konta Google: do zalogowania i sprawdzenia uprawnień.
- Dostęp do Gmaila tylko do odczytu: wyłącznie do odczytania wybranych wiadomości wskazanych przez użytkownika. Aplikacja niczego nie wysyła, nie zmienia ani nie usuwa.

Dane nie są sprzedawane, udostępniane osobom trzecim ani używane do reklam lub trenowania modeli AI. Wykorzystanie informacji z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymogami Limited Use.

## Cofnięcie dostępu

Dostęp można cofnąć w dowolnej chwili na stronie https://myaccount.google.com/permissions.
